# Illustrations locales

Déposez ici les illustrations originales, une par entité :

- `boss/<slug>.webp` : portrait de boss, format 3:4, environ 900 × 1200 px, moins de 200 ko.
- `zone/<slug>.webp` : bandeau de zone, format 16:10, environ 1600 × 1000 px, moins de 300 ko.
- `pnj/<slug>.webp`, `fin/<slug>.webp`, `lore/<slug>.webp` : format libre, au format WebP.

Pour les activer, déclarez-les dans `src/data/illustrations.ts` avec leur texte alternatif, leur crédit et leur licence, puis lancez `npm run data:validate`.

N'ajoutez jamais d'image officielle ni d'image dont les droits ne sont pas établis.
